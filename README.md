# SORBA Quiz — Sessão de casos (Hospital São Rafael)

Quiz ao vivo no estilo Kahoot com as 16 perguntas dos 6 casos.

- Abra o link do GitHub Pages no computador do telão: aparece a tela do apresentador com o QR code.
- O público escaneia o QR code, digita o nome e responde pelo celular.
- Ranking por número de acertos (pontos de rapidez desempatam). No final, é possível baixar o resultado em CSV.
